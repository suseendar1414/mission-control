## Funnel rule for the manual loop
1. Research moves an account from C to B only when one hard requirement is proven on an exact source.
2. It moves from B to A only when both 10+ managed client websites and client-zone/portfolio Cloudflare reliance are proven, and a usable buyer/contact route exists.
3. Only A records should be represented to the outreach writer as fully qualified. B records can support drafts only if the wording explicitly asks the missing qualifying question and does not imply the unknown fact.
4. Replies should be logged against the same account with objection, wording that triggered the reply, ICP corrections, and next action. No automated send while the human review gate remains.
